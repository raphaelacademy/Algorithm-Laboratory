# 📐 Linear Algebra Laboratory

Neste módulo, exploro a implementação do zero de conceitos de Álgebra Linear em Python, construindo as bases matemáticas manualmente antes de migrar para abstrações e bibliotecas de alto nível.

---

## 📌 Status Atual & Scripts

* **`vector_math.py`**: Implementação inicial de operações fundamentais com vetores 2D (soma vetorial elemento a elemento).

---

## 🧠 Aprendizados & Reflexões de Campo

* **Construção de Abstração:** Implementar operações algébricas manualmente força a entender o que acontece "por baixo do capô" das estruturas de dados (listas vs. matrizes).
* **Desafios Enfrentados:** Mapear a representação matemática (componentes $x, y$) para índices de listas em código exige atenção para evitar erros de indexação e garantir generalização para $n$ dimensões no futuro.

---

## 🗺️ Roteiro de Evolução (Roadmap)

- [x] Soma simples de vetores 2D em listas nativas
- [ ] Implementação de produto escalar (Dot Product)
- [ ] Representação de vetores via matrizes e operações de multiplicação
- [ ] Funções para cálculo de norma (módulo) e ângulo entre vetores
